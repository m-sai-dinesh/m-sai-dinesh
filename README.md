## 👋 About Me

I don't debug code. I interrogate it until it confesses.

Third-year CS student by title, backend engineer by obsession. My APIs are stateless, my JWTs are signed, my CORS errors are somebody else's fault, and my `console.log` statements are strictly a "temporary measure" that has now lasted three sprints.

I clear LeetCode problems the way other people clear their notifications: **max rating 1744, 350+ solved**. I've shipped serverless backends, a Chrome extension that fills job forms by itself, and a chunked video upload pipeline. My GitHub Actions run so reliably that they're the only thing in my life with a 100% pass rate.

```diff
+ Fluent in: Node.js, Express, MongoDB, REST, JWT, Docker, system design
+ Powered by: coffee, stubbornness, and one suspiciously well-behaved Postman collection
```

> **CURRENT MISSION:** Teaching my toaster to authenticate users with JWT, then rate-limiting it so it stops burning my bread.
